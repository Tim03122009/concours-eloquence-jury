Vidéo

Lecteur vidéo plein écran (fond noir). Un petit point en haut à droite passe du blanc au rouge selon l’avancement de la lecture.

Ouvrir le panneau : Ctrl+A (ouvrir / fermer).

Mode 1 — Dossier local (un seul appareil) :

  • Dans le panneau, cliquer sur « Choisir un dossier » (Chrome / Edge)
  • Parcourir l’arborescence et cliquer sur une vidéo (.mp4, .webm, .mov, etc.)
  • Lecture locale uniquement — pas de synchronisation entre appareils

Mode 2 — Vidéo partagée (plusieurs appareils) :

  • Coller une URL publique dans « Vidéo partagée », puis « Définir pour tous »
  • L’URL et l’état (play / pause / position) sont synchronisés via Firebase
  • Tous les écrans ouverts sur video.html suivent la même lecture en temps réel

Contrôles :

  • Espace ou clic sur la vidéo → lecture / pause
  • Entrée → revenir au début + pause
  • Ctrl+A → ouvrir / fermer le panneau
  • Barre de progression (dans le panneau) → se repositionner dans la vidéo
